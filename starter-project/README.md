# Earlier Unreal starter

The local development folder used [SatisfactoryModLoader](https://github.com/satisfactorymodding/SatisfactoryModLoader) as an earlier Unreal/modding starter. Its full source checkout and game/editor content are not included in this repository. The current application is in `external-tool/` and does not require Unreal Engine or SML.

The original license and credits are retained here for attribution. Get the starter from the upstream repository if you want to explore that separate track.
